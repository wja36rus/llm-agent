## 🔧 Как это работает

### Архитектура

1. **AST Анализатор** (`analyzer.ts`)
   - Парсит исходный код с помощью Babel
   - Извлекает информацию о функциях, компонентах, хуках
   - Определяет типы параметров и возвращаемых значений

2. **Генератор промптов** (`promptGenerator.ts`)
   - Создает оптимизированные промпты для LLM
   - Использует few-shot обучение на примерах
   - Адаптирует промпты под тип функции

3. **Клиент Ollama** (`ollamaClient.ts`)
   - Отправляет запросы к локальной LLM
   - Настраивает параметры генерации (temperature и др.)
   - Обрабатывает ответы модели

4. **Запускатель тестов** (`testRunner.ts`)
   - Запускает Jest тесты
   - Кэширует результаты
   - Автоматически исправляет упавшие тесты

5. **CLI Интерфейс** (`index.ts`)
   - Обрабатывает команды и опции
   - Координирует работу всех модулей
   - Выводит отчеты и статистику

### Процесс генерации теста

1. Сканирование файлов в директории `src`
2. AST анализ каждого файла
3. Определение типа (компонент, утилита, хук)
4. Формирование промпта с контекстом
5. Отправка запроса в Ollama
6. Извлечение и пост-обработка кода теста
7. Сохранение теста в `__tests__` директорию
8. (Опционально) Запуск теста и исправление ошибок

### Процесс автоисправления

1. Запуск теста через Jest
2. Анализ ошибок и падений
3. Формирование промпта для исправления
4. Генерация исправленной версии
5. Повторный запуск теста
6. Повторение до 3 попыток (настраивается)

## 🐛 Устранение проблем

### Проблема: Ollama не отвечает

**Решение:** Убедитесь, что Ollama запущен:

```bash
ollama serve
ollama list # Проверка доступных моделей
```

### Проблема: Ошибка "ts-jest not found"

**Решение:** Установите необходимые пакеты:

```bash
npm install --save-dev ts-jest @types/jest
```

### Проблема: "Cannot find module '@testing-library/jest-dom'"

**Решение:** Установите Testing Library:

```bash
npm install --save-dev @testing-library/jest-dom @testing-library/react @testing-library/user-event
```

### Проблема: Тесты не генерируются для определенных файлов

**Решение:** Проверьте паттерны исключений в конфигурации:

```bash

# Используйте явное указание опции exclude

npm run generate all -- --exclude=""
```

### Проблема: Медленная генерация тестов

**Решение:** Используйте более легкую модель или ускорьте Ollama:

```bash

# Используйте модель поменьше

ollama pull deepseek-coder:1.3b

# Или используйте GPU ускорение (для NVIDIA)

# Установите CUDA и перезапустите Ollama

```

### Проблема: Ошибка "Multiple configurations found"

**Решение:** Оставьте только один конфигурационный файл Jest:

```bash

# Удалите лишние конфиги

rm jest.config.cjs jest.config.ts 2>/dev/null

# Удалите секцию jest из package.json

# (отредактируйте вручную или используйте скрипт)

```

### Проблема: setupTests.ts not found

**Решение:** Создайте файл вручную:

```bash
mkdir -p src
echo "import '@testing-library/jest-dom';" > src/setupTests.ts
```
